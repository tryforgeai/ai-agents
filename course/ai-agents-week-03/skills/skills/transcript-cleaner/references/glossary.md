# Transcript jargon glossary

Restore these terms when the speech-to-text service mangles them.

| Heard / mangled | Correct term |
|-----------------|--------------|
| group O | GRPO |
| logic | logits |
| attention is all you need | Attention Is All You Need |
| L L M | LLM |
| reinforcement learning from human feedback | RLHF |
| agent development kit | Agent Development Kit (ADK) |
| skill craft | Skillcraft |

When a term is ambiguous, prefer the technical reading that fits the lecture
context.
