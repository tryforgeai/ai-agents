# Conventional commit format

```
<type>(<scope>): <imperative summary>

<optional body — why this change matters>

<optional footer — BREAKING CHANGE:, Fixes #123>
```

**Types:** feat, fix, docs, style, refactor, perf, test, chore

**Example:**

```
feat(skills): add filesystem skill registry for ADK

Load skills from the repo root so new folders appear without code changes.
Governor runs firing tests on descriptions and validation tests on procedures.
```
