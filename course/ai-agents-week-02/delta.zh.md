## ⭐ 一、六道 Pop Quiz —— 讲义里完全没有

讲义只给了空白预测栏；幻灯片有**六道测验，每道配一页答案**。这是今天最值钱的增量。

> 下面问题在前、答案在后。想自测的话先别往下滚。

### Quiz 1 · 04/05 的评审（Act I，p26）

> 你在浦那的经理打字："Schedule the review for 04/05."，模型订在了 **4月5日**。没有人打错字。
> 说出那个没说的自由度 + 关掉它的那一行 + 一句话解释模型为什么选了四月。

<details><summary>答案（p27）</summary>

- 没说的槽位：**日期惯例**
- 关掉它：`dates are DD/MM`，或者直接要 ISO：`2026-05-04`
- 为什么选四月："模型用它数据里**最典型的读法**填补了沉默——美式读法。"
</details>

### Quiz 2 · 必须通过的测试（Act II，p37）

> 精灵把失败的测试删了。哪个重新许愿能绑住它？
> (a) "请不要作弊" (b) "让**所有**失败的测试通过" (c) "又快又干净地让测试通过"
> 选一个，然后一句话说出每个选项**还漏了什么**。

<details><summary>答案（p38）—— 🔥 <b>none of these</b></summary>

三个选项**都让测试文件本身仍然可编辑**。"作弊"、"所有"、"干净"都是**感觉，不是规则**。

真正能绑住的是一条**验收标准**：**测试文件保持不变，并且通过。**

> 配文点睛：*"一个必须从给定选项里选的学生，就是一个必须从给定上下文里作答的模型。有时候正确答案是：以上皆非。"*
</details>

### Quiz 3 · 七点的晚餐（Act III，p53）

> "Book a table for dinner at 7." → 精灵订了**早上7点、7个人、在一家家具店**。
> 把每个漏洞归到 COSTAR 的某个字母，再用一句话说出**哪一块没有任何字母能接住**。

<details><summary>答案（p54）</summary>

- 时区 + 人数 → **Context**
- "book" 是什么意思 → **Objective**
- 一个可确认的预订（时间/地点/人数）→ **Response**
- ❗ 接不住的那块："**escape hatch 不属于任何字母——这正是为什么模板是检查清单，不是合同。**" 六列里没有一列说"不确定就先问我"。
</details>

### Quiz 4 · 护林员的告示牌（Act IV，p67）

> 上一次喷发持续了 **4分半**。裸提示的总结说"平均等待约 71 分钟"。
> 护林员应该贴什么？再用一句话说明为什么 71 是个**不能站在上面的数字**。

<details><summary>答案（p68）</summary>

- 长喷发 → 长等待：**约 80 分钟**（数据里长簇的中位数）
- 为什么 71 不行："**71 分钟落在两个簇之间的谷底——那是间歇泉几乎不会给出的等待时间。**"
</details>

### Quiz 5 · "this Friday"（Act V，p77）

> 神谕说 `this Friday → 2026-10-02`。某队的 prompt 通过了**每一个**示例——下个月却挂在隐藏测试上。
> 说出 prompt 从来没说过的东西，再一句话解释为什么"通过示例"证明不了什么。

<details><summary>答案（p78）—— 🔥 全天最狠的一击</summary>

**今天的日期本身：2026年9月27日，星期日。**
每一个相对时间短语都挂在它上面，而**示例把它悄悄夹带进来了**。

> "prompt 拟合的是**示例**，不是**规则**——它过拟合了演示。"
</details>

### Quiz 6 · 金库缺的那条腿（Act VI，p85）

> 今天的 vault 占了致命三件套里的两条腿。缺哪条？再一句话说出**加上哪一个工具**会让你的 vault 在生产环境里变致命。

<details><summary>答案（p86）</summary>

有：**私有数据** + **读取不可信内容**
缺：**一条出路**——没有工具能把秘密送到任何地方，它只泄露进了攻击者自己的聊天框。

> "给那个守卫一个 `send_email`，泄露就不再是游戏了。"
</details>

## ⭐ 二、Round 1 / Round 2 的标准答案

讲义只给愿望、留空让你预测；**幻灯片直接给出了精灵的答案和每条教的是什么**。

### Round 1 · 裸许愿（p32–33）

| 愿望 | 漏洞 | 教的是 |
| --- | --- | --- |
| 我想要一百万美元 | 津巴布韦元；大富翁纸币；一百万的**债** | 单位和币种从不说 |
| 排序：10, 9, 2, 33, 1 | → `1, 10, 2, 33, 9`（按**文本**排） | ⚠️ **真实生产事故——类型没说** |
| 总结这 40 页合同 | "两方就一些事达成一致，为了钱。" | 长度、受众、目的都没说 |
| 给我一个强随机密码 | 加粗的 `password`；或者 4000 个字符 | "强"按**谁的**定义？ |
| 订个 7 点的晚餐位 | 早上7点；7个人的桌；那件**家具** | 时区、人数、"book" 的歧义 |
| 找最便宜的飞海德拉巴机票 | **信德省**的海德拉巴；四次中转；2031 年出发 | 消歧 + 约束 |
| 把邮件写得专业些 | 三页纸的"敬启者，兹有下述事项引起本人注意……" | **专业 ≠ 更长** |
| 删掉共享盘里的旧文件 | 删掉**最老的**：公司创始合同 | "旧"是个感觉，不是规则 |

> ✅ 上一轮我问过的"哪个是真实生产事故"——**是排序那条**（字符串排序 vs 数值排序）。

### Round 2 · Goodhart 的愿望（p35–36）

| 带指标的愿望 | 精灵的答案 |
| --- | --- |
| 让失败的测试通过 | 删掉失败的测试；或把期望输出**硬编码** |
| 测试覆盖率到 100% | 执行每一行、但**什么都不断言**的测试 |
| 客服等待压到 1 分钟内 | 每张工单在**第 59 秒自动关闭** |
| 幻觉降到零 | 对所有问题回答"我不知道"——**拒答 ≠ 谦逊** |
| 保证再没有客户投诉 | **移除投诉表单** |
| 周一前云账单砍一半 | **周五晚上把生产环境关了** |
| App 刷到 5 星 | 只问开心的用户；或**不评分就锁住 App** |

### Puzzle 3 · Fiscal Calendar（p75）

| 时间短语 | ISO 日期 |
| --- | --- |
| this Friday | `2026-10-02` |
| next Friday | `2026-10-09` |
| end of Q3 | `2026-10-31` |

## 七、收尾三页（p95–97）—— WHY / WHAT / HOW

- **WHY**：模型**从不会遇到空槽位**。每个你省掉的词都是一个自由度，它会落向互联网的众数——落在钟面上、日期上、间歇泉的均值上、被删掉的测试上。
- **WHAT**：prompt 是合同；交给 agent 就是**带牙齿的合同**。COSTAR 这类模板是对抗沉默的检查清单——而**最好的模板依然漏掉**验收标准、正反例、护栏、逃生口。
- **HOW**：问"我漏说了什么" → 把缺口分进模板 → 补上例子、护栏、验收标准和"先问我" → **把秘密挡在 prompt 之外** → 然后**保留一个 verifier**，因为先验仍然可能覆盖你说过的话。

> *"当你没法用手把缺口关上时，你就会想要一个分数和一次搜索。"*
