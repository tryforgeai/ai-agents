# 口头汇报提纲格式

> **只在这篇论文要在课上讲时才读这个文件。** 写笔记本身不需要它。

六段，标注每段用时，总计 5 分钟：

```
1. 问题（30 秒）             现状为什么不够
2. 洞察（30 秒）             关键的那一下转念
3. 方法（1 分钟）            公式 + 循环 + 走一个具体例子
4. 实验（1.5 分钟）          挑最有冲击力的对比数字，不要全报
5. 最有意思的发现（1 分钟）   三条，优先反直觉的
6. 局限与影响（30 秒）       承认局限，收在「它定义了什么」
```

## 两条写法

**第 2 段要讲「转念」，不是讲方法。** 方法是第 3 段的事。
例（ReAct）：*"人类做复杂任务时推理和行动是交织的——所以把『思考』当成一种**不改变环境的动作**，
塞进同一个动作空间。"*

**第 4 段挑数字的标准是冲击力，不是完整性。**
例：「one/two-shot 打赢用 **10⁵** 条专家轨迹训练的模仿学习」
比罗列四个 benchmark 的分数有用得多。听众记得住前者，记不住后者。

**第 5 段优先选反直觉的。** 「ReAct 幻觉率 **0%** vs CoT **56%**」
「能拿到比数据集标签更新的答案，因此反而被判错」——
这类发现才会让人提问，而提问是汇报成功的标志。
