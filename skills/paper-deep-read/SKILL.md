# 论文精读笔记

把一篇论文变成**三个月后还能用**的笔记：能复习、能引用、能在课上提出有分量的问题。

不是摘要。摘要回答「这篇讲了什么」，精读笔记回答「**这篇的哪个数字我记得住、哪句话我能引用、哪里站不住脚**」。

## 标杆样例

动笔前翻一份已有的，对着它的密度和语气写：

- `Generative Agents 论文精读笔记.md` —— 方法精读与失败模式写得最细
- `ReAct 论文精读笔记.md` —— 带口头汇报提纲的那份
- `Voyager 论文精读笔记.md` —— 谱系对比和「论文内部不一致」写得最全

**写完和它们并排看一眼：密度够不够？数字够不够密？批评够不够硬？**

## Procedure

1. **先确认来源。** 拿到 arXiv 编号/PDF/链接，读正文、附录和图表。
   **附录和图经常是含金量最高的部分**——不要因为在后面就略读。
   拿不到原文就停下来问，**不要凭印象写**。

2. **写 `## 0. 一句话总括`。** 一句加粗的话说完整篇，紧跟一句
   「核心贡献不是 X（那是某某论文），而是 Y」——**把它放回谱系里**。
   有方法论硬伤的（没有 verifier、没有 ground truth、评测只能证明弱主张），
   在这里就用 ⚠️ 挑明，并说明它如何限定了论文能提出的主张
   （例：没有 ground truth → 只能主张 believability，不能主张 correctness）。

3. **按骨架展开**，每节按下面「各节写法」写。

4. **一边写一边记数字。** 凡是具体数字（样本量、阈值、权重、百分比、模型名、耗时）
   一律**加粗**，并同步记进最后的速查表。

5. **分开「论文说的」和「我说的」**，按下面的标记约定。

6. **找论文内部的不一致。** 同一件事在正文、图注、附录里给了不同数字或说法，
   用 ⚠️ 并排列出，说明两者度量方式的差别。**这是精读和摘要最大的区别。**

7. **自检。** 先跑脚本，再人工对照 Done when：

   ```bash
   python3 scripts/check_numbers.py "<笔记.md>"
   ```

   **必须跑这个脚本，不要自己比对两份数字清单。** 这是一件确定性的、重复的、
   极容易看漏的工作——实测同一个模型做类似核对，三次给出三个不同答案。
   脚本只负责**标出**可疑项；**哪些该补进速查表、哪些是引文内部或章节号，由你判断。**

## 骨架

必备（顺序固定）：

```
0.  一句话总括
1.  动机与定位
2.  方法精读            ← 最长的一节，逐个机制拆开
3.  实验（按论文的实验数拆成 3. / 4. ...）
N.  失败模式与局限       ← 论文分开写就分开，合并写就合并
N+1 在 agent 谱系里的位置
N+2 批判性分析（分「论文承认的」/「我补的」两小节）
N+3 复习自测题
N+4 核心数字速查表
```

按论文增补（有才写，不要硬凑）：

- **埋起来的洞察**（标 ⭐）—— 来自**附录、图、表**，正文没突出的。两类都算：
  论文**压根没说**的（你从图里看出来的），和论文**说了但埋在附录里**的。
- 论文内部两处说法的矛盾（标 ⚠️）
- 伦理与社会影响（论文有专节时）
- 与本课程某一周的对照（标 ↔）
- **口头汇报提纲** —— 仅当这篇要在课上讲时才写，格式见 `reference-talk-outline.md`

## 标记约定

| 标记 | 用在哪 | 例 |
| --- | --- | --- |
| `> *"English"*` | **原文引用，保留英文**，不要翻译后再引 | `> *"Agents are not omniscient"*` |
| 🔑 | **我的提炼**，论文没这么说 | 🔑 记忆流的大部分是噪声 |
| ⭐ | **自己从附录/图/表里挖出来的**，注明出自哪张图哪一节 | ⭐ 图 6 —— 记忆流里绝大部分是家具在汇报"没事发生" |
| ⚠️ | 论文内部不一致、或读者容易误读的地方 | ⚠️ 两个不同的数字：访谈说 13 人，图 9 说 12 人 |
| 🔥 | 整节含金量特别高 | 🔥 失败模式（含金量最高的一节） |
| ↔ | 与课程某一周或另一篇论文的对照 | ↔ 和 Week 02 的上下文膨胀是同一类问题 |
| **粗体** | 所有具体数字、关键术语、反直觉的结论 | **0.995**、**gpt-3.5-turbo** |

**一致性比数量重要。** 同一个标记在整篇里只表示一件事。

## 各节写法

**1. 动机与定位** — 摘要里列的用途**顺序有讲究**，照抄下来并指出哪一条是它被某个圈子重视的原因。
🔑 评测标准要和用途匹配：不要拿「它会不会算错」去批一个为探索而造的系统。

**2. 方法精读** — 最长的一节。每个机制一个小节：公式或流程 → **论文实现的具体参数**
（权重多少、阈值多少、衰减因子多少）→ 有原始 prompt 的**照抄进来** → 最后一句 🔑
点出这个机制的真实作用或脆弱处。

**实验节** — 每个实验：设置 → 数字 → **作者没报的那部分**。
把失败的、缺席的、不显著的单独拉出来讲（例：派对 12 人受邀 5 人到场，
**把 7 个没来的逐一列出来**）。作者的诚实之处值得学，含糊之处值得点。

**失败模式** — 通常是全篇最有价值的一节。
每条：原文怎么说 → 具体表现 → 🔑 它属于哪一类更一般的问题。

**谱系** — 必须是表格，和用户**已读过**的论文并排。至少包含：各自管哪一层
（记忆类型 / 任务尺度 / 机制）、**有没有 verifier / ground truth**。
最后一段说清「它不是 X 的替代，是 X 之上/之下的一层」。

**批判性分析** — 两小节：
- `论文自己承认的` — 指回论文的局限一节，不重复展开
- `我自己补的` — 编号列，**每条一个加粗标题 + 理由**。好的批评指向结构问题
  （「这不 scale」），不是参数（「阈值选得不好」）。指出一个**值得做的复现实验**是加分项。

**复习自测题** — 12 题左右，**至少一半问到具体数字或机制细节**。
反例：「这篇论文的主要贡献是什么？」——空题。
正例：「recency 衰减的是距创建还是距上次访问？衰减因子多少？」

**核心数字速查表** — 两列表格，所有加粗过的数字在这里再出现一次。
**考前扫一眼**用的，不加解释。

## Done when

- [ ] 每个具体数字都加粗了；**速查表收齐所有「结论性」数字**——实验结果、参数、阈值、模型名。
      引文内部的数字、论文章节号、以及你自己推导的中间值不必进表，但推导出的**结论值要进**。
- [ ] 至少一条 `> *"原文英文引用"*`，且标明出自哪一节
- [ ] 「论文说的」和「我提炼的」在视觉上分得开（🔑 / ⭐ / ⚠️ 用法一致）
- [ ] 批判性分析有「我自己补的」那节，**不少于三条、每条带理由**
- [ ] 自测题**至少一半问到具体数字或机制细节**
- [ ] 谱系那节和用户已读过的论文做了对比，不是孤立介绍
- [ ] 文件写进 vault，命名 `<论文名> 论文精读笔记.md`

## 两条底线

1. **区分论文说的和你推的。** 读者三个月后回来，必须一眼看出哪句能直接引用。
2. **不确定就标不确定。** 引用数被查的日期、有争议的译法、论文没给数值的参数，
   全部注明，不要让它们看起来像确定的事实。

拿不到原文、或者只能基于摘要和二手描述写 —— **明说，不要交付一份看起来完整的笔记。**
