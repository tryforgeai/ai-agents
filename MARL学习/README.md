目标：理解多智能体强化学习，完成一个小型协作实验，再用 MABIM 做库存补货对照实验。

## 从这里开始

1. 打开 [学习路径](00-学习路径.md)，根据起点选择阶段。
2. 今天完成 [第一课](笔记/01-第一课.md)，约 60–90 分钟。
3. 查资料用 [资料索引](01-资料索引.md)，查术语用 [概念速查](02-概念速查.md)。
4. 每完成一个阶段，在 [学习进度](03-学习进度.md) 勾选，并留下笔记或实验结果。
