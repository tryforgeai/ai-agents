## 已发现的版本注意点

- [MPE 迁移说明](https://pettingzoo.farama.org/environments/mpe/)：相关环境已迁到独立 MPE2 项目。新旧教程的导入路径可能不同。
- 《动手学强化学习》第 21 章示例明确使用旧版 Gym；把教材作为原理和代码阅读材料，运行时单独处理依赖。
- MABIM README 说明 MARL 训练只在 Linux 测试过。Mac 上可以先学模型和读代码，实际训练环境在启动实验时再验证。
- 文档页眉的版本文字不代表你本机安装的版本；框架示例、环境 API 和依赖版本应配套记录。
