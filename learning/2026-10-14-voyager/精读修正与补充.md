# 对 Voyager 精读的修正与补充

依据：2026-10-14 已分享课件、当天问答、已读论文 v2。以下同时审视原有《Voyager 论文精读笔记》和当天《精读导读》。原笔记并未进行全文重新核验；这里明确哪些结论应替换、哪些仍需回原文验证。

## 必须修改的判断

| 原表述或容易产生的理解 | 改为 | 原因 |
|---|---|---|
| 权重没变，因此没有更聪明 | 模型参数固定，系统能力可以提高 | Rosso 的质疑成立：经验积累属于实际能力，不能把参数学习当唯一学习 |
| 代码天然就是 option | 代码技能可用 option 框架分析，但需要说明启动条件、策略和终止 | 描述向量相似不等于 initiation set；critic 不等于 termination function |
| 代码保证如何执行或保证成功 | 代码明确执行逻辑，实际结果仍依赖条件和环境 | 语法、依赖、前置条件、状态变化都可能失败 |
| 有 verifier，因此“环境说了算”或拥有绝对 ground truth | 环境提供证据，GPT-4 作成功判断，可能误判 | 羊毛和腐肉例子是间接证据，不是可靠事件计数 |
| 自验证是必要的，只有课程和技能库支撑时才有用 | 去掉自验证使本实验表现明显下降，但未证明必要性或特定交互关系 | 退化不等于完全失效；交互作用需进一步对照实验 |
| 木器、石器阶段有技能库都更差 | 木器完整系统 6 对 7 略优；石器 11 对 9 略慢 | 原笔记的事实错误；三次试验也不足以确定真实差异 |
| 技能库只在足够复杂时有用，存在已证明的启动门槛 | 后期优势更明显是观察；复用开销、复杂度门槛是待检验假设 | 不能从小样本表格直接推出因果机制 |
| GPT-4 才能工作／换 GPT-3.5 循环不能运行 | 在论文设置中 GPT-4 表现更好，较弱模型仍能运行 | 模型能力重要，但不是“可运行”的绝对开关 |
| Generative Agents 没有评估，因此只能主张像真人 | 不应把不同研究的验证机制和评估目标压缩成“有／没有” | 需要单独读其评估；不能据此归因哪个系统主要靠架构 |
| 没有人为课程或设计 | 任务动态生成，但提示规则、API、热身阈值由人设定 | 自动化的是具体选题，不是研究者设计全部消失 |
| 无 reward 意味着没有评价 | 没有奖励驱动的参数更新，仍有成功判定和环境反馈 | 区分训练信号与运行时反馈 |
| 先前只能重训才能保留方法 | 外部程序与记忆也能持久保存 | 课件的历史优先权叙述过强，不能直接当事实 |
| 每次运行几十美元是论文结果 | 是讲者粗估，论文没有给出该金额 | 缺少完整调用量、token 与价格计算依据 |
| 15.3× 是整体速度或复杂任务加速 | 木工具提示迭代之比 | 不能换算为墙钟时间、费用或总体智能 |
| 63 种物品就是 63 项技能 | 这是探索广度指标 | 物品、技能与可靠性是不同测量对象 |
| 死亡几乎免费 | 保留背包降低了损失，但仍可能消耗时间和进度 | 不把宽容设置夸大成没有失败成本 |

## 对当天精读导读的具体补充

原导读的中心判断保留。补上以下可定位的内容，详细展开见同目录课堂笔记：

1. 三个模块与三个 GPT-4 角色不一一对应；技能库不是第三个 GPT-4 角色。
2. 添加数据流：API 和状态 → 代码 → 执行 → feedback/errors → critic → success/critique → 再生成或入库。
3. 明确 critic 的 critique 是改进意见，不是解释器错误；程序正常退出也可能任务失败。
4. 区分 GPT-3.5 的辅助问答、技能描述生成与 GPT-4 的代码生成、自验证角色。
5. 写清检索键是描述 embedding，值是程序；query 含解题建议和环境反馈，top-5 是候选。
6. 加入热身表，阈值按完成任务计数，仅针对课程输入；不要宣称整个系统状态被屏蔽。
7. 加入“重复环境中的成功不等于可迁移技能”与跨状态验证建议。
8. 给技能金字塔、搜索空间公式、人类学习和文明类比加上“示意／分析”标签。
9. 保留三次试验的离散结果，别只保留平均数与摘要倍数。
10. 区分任务终止、任务成功、代码正确性与跨状态可靠性。

## 证据纪律

- 62.7/19.3 与摘要 3.3× 的差异可以报告，不能自行给作者的取数方式下定论。
- 课程热身是否减少信息干扰，是合理解释，不是已证明结论。
- 代码技能是否改善长期探索，应结合有／无技能库比较；不能把全部优势归给单一模块。
- 不能仅从 GPT-4 对 GPT-3.5 的比较推断“必须用某个模型”，也不能用跨论文不同任务的结果量化模型与架构各自贡献。
- 原笔记关于地图覆盖指标、检索评估和未做哪些消融的强断言，仍应单独对照附录核查；本次没有把它们视为已经证实的新发现。
- 局限章节在论文 v2 是 §4；原笔记自身的“第 6 节”与论文节号应明确区分。
